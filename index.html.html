⚡ 反射軌道シミュレーター β

使い方

  1. スクショ読込 … ゲーム画面を読み込み
  2. エッジ検出 … 壁っぽい線を薄く表示
  3. 上下壁 / 左右壁 … 画面を上下（or左右）にドラッグして壁の位置を決める。水平・垂直の線が出ます
  4. ブロック … 内部の障害物を配置（タップ追加・ドラッグ移動・ダブルタップ削除）
  5. キャラ … モンスターの位置をタップ
  6. 軌道予測 … 上下左右の壁をタップして1反射目を指定、またはスワイプで方向指定

※ 実際のモンストと完全一致するわけではありません。
参考程度にご利用ください。
